# Plan A2e: आसानी, तीसरा दौर: फ़ोन और desktop (TR-32)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans

**Goal:** मालिक की माँग (2026-11-23): "फ़ोन और desktop दोनों में अच्छा, और आसान, नई सुविधाएँ"। desktop पर जाँच (1366×768) से मिली कमियाँ और पीड़ित के सबसे कठिन कदम।

## बदलाव
1. "पहले पूछो": **"चिपकाएँ" बटन** (एक tap में copy किया message डिब्बे में, और तुरंत जाँच)। clipboard सिर्फ़ बटन दबाने पर पढ़ा जाता है, कहीं भेजा नहीं जाता; browser न दे तो वही "उँगली दबाकर Paste" वाली मदद।
2. **ज्ञानकोश में खोज:** /gyan पर डिब्बा; शब्द लिखते ही पन्ने छँटें (नाम, सार, निशान, उदाहरणों में), नुक़्ता/मात्रा का फ़र्क़ नहीं। बिना JS के पूरी सूची।
3. **ज़रूरी नंबर छापें:** /nambar पर "Print / PDF", सिर्फ़ नंबरों वाला हिस्सा (data-print-area), एक पन्ना।
4. **desktop:** ऊपर के menu में "ज्ञानकोश" और "ज़रूरी नंबर"; जो पन्ना खुला है वह menu में दिखे (aria-current, फ़ोन के नीचे वाले menu में भी); /turant की पट्टी बीच के हिस्से से मिले और उसमें साइट का नाम; tiles/links पर hover।
5. **सुलभता:** हर ढाँचे में "मुख्य हिस्से पर जाएँ" (skip link), keyboard से पहला Tab उसी पर।

## जाँच
- unit: खोज का function (TDD), nav में "ज्ञानकोश"/"ज़रूरी नंबर" (सिर्फ़ desktop सूची), skip link।
- e2e: चिपकाएँ (clipboard अनुमति के साथ; कोई request नहीं), खोज, नंबर print (1 पन्ना), desktop menu + aria-current, skip link पर पहला Tab, 320px/सबसे बड़े अक्षर, सुलभता light/dark।
